# Toronto Medical Dispatch Analysis (2024)

This repository contains an in-depth analysis of Toronto medical dispatch data in 2024.  
Explore the interactive choropleth map here: [Interactive Map](https://this-is-leo.github.io/Toronto_Medical_Dispatch/Src/toronto_paramedic_dispatch_map.html)

---

## Contents

- **Data/** – Raw and processed datasets  
- **Notebook/** – Jupyter notebooks for analysis  
- **src/** – Python scripts and the interactive HTML map (`toronto_paramedic_dispatch_map.html`)  
- **Visualization/** – Charts and images  
- **requirements.txt** – Python dependencies

---

## Summary

This project analyzes temporal and spatial patterns of medical dispatches across Toronto neighborhoods, emergency codes, and times. It includes insights and recommendations for improved emergency response planning.
