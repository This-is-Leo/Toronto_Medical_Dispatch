# Toronto Medical Dispatch Analysis (2024)

This repository contains an in-depth analysis of Toronto medical dispatch data in 2024.

## Contents
- **Data/**: Raw and processed datasets.
- **Notebook/**: Jupyter notebooks for analysis.
- **src/**: Python scripts and interactive HTML map (`toronto_paramedic_dispatch_map.html`).
- **Visualization/**: Charts and images.
- **Requirement.txt**: Python dependencies.

## Summary
Analyzed temporal patterns across neighborhoods, emergency codes, and times. Derived actionable insights and recommendations for improved emergency response.
